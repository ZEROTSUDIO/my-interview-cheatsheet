Basic I/O & Types

Reading input, printing output, and casting types — the starting point of every problem.

input()print()map()ord / chr Reading Input & Type Casting
What & Why
Every competitive / interview problem starts with reading input and printing output. Python's input() always returns a string — you must cast it. map(int, input().split()) is the fastest way to read space-separated integers on one line.

Common use cases
  • Read a single integer: n = int(input())
  • Read two ints on one line: a, b = map(int, input().split())
  • Read n lines into a list: [int(input()) for _ in range(n)]
  • Format output: f-strings are the cleanest — f"{val:.2f}" for floats
Edge cases to remember
ord('a') = 97, chr(97) = 'a' — useful for letter-index tricks like ord(c) - ord('a').

n    = int(input())           # cast immediately

print(f"Hello, {name}!")
print(a, b, sep=", ", end="\n")

Control Flow

if/elif/else, loops, ternary, range tricks — Python's bread and butter.

if / eliffor / whilerange()ternary Conditionals, Loops & Range Tricks
What & Why
Python uses indentation for blocks — no braces. Key difference from other languages: there is no i++, use i += 1. The else clause on loops runs only if the loop was NOT broken out of — rarely used but useful to know.

Range tricks
  • range(n) → 0 to n-1
  • range(a, b) → a to b-1
  • range(n-1, -1, -1) → n-1 down to 0 (reverse iteration)
  • range(0, n, 2) → every other index
Ternary: x if condition else y — same line, cleaner than a full if/else block.

Strings

Immutable sequences — slicing, methods, f-strings, and the join pattern.

str methodsslicingf-strings"".join() String Methods, Slicing & Building
What & Why
Strings in Python are immutable — you cannot change a character in place. Any "modification" creates a new string. This has performance implications: building a string with += in a loop is O(n²). Use a list and "".join() instead.

Common interview use cases
  • Palindrome check: s == s[::-1]
  • Anagram check: sorted(s) == sorted(t) or use Counter
  • Split by whitespace: s.split() (handles multiple spaces)
  • Letter frequency: Counter(s)
  • Index of a char: ord(c) - ord('a') → 0-based index
Slicing: s[start:stop:step]. Negative step reverses. Out-of-bound indices don't crash.
⚠️ Strings are immutable. Building a string with += in a loop is O(n²). Use a list and "".join(buf) instead — O(n).

s.isdigit() / s.isalpha()

Lists

Dynamic arrays — the Swiss Army knife. Append/pop O(1), comprehensions, sorting.

list opscomprehensionsort / keydeque List Operations, Comprehensions & Sorting
What & Why
Python lists are dynamic arrays. Append/pop from the end are O(1). Insert/pop from the front (pop(0)) are O(n) — use deque for that. Sorting is Timsort: O(n log n).

Common interview patterns
  • 2D grid initialization: [[0]*cols for _ in range(rows)] — never use [[0]*cols]*rows (shares references)
  • Get last element: arr[-1]
  • Reverse in place: arr.reverse() or arr[::-1] (copy)
  • Sort by custom key: arr.sort(key=lambda x: x[1])
  • Flatten: [x for row in matrix for x in row]
enumerate vs range(len): always prefer for i, v in enumerate(arr) over for i in range(len(arr)).
⚠️ pop(0) is O(n). For queue (dequeue from front), use collections.deque with popleft() which is O(1).
common ops

a = [3, 1, 4, 1, 5]
a.append(9)          # add to end    O(1)
a.pop()              # remove last   O(1)
a.pop(0)             # remove first  O(n)!
a.insert(2, 99)      # insert at idx O(n)
a.remove(1)          # removes first match
a.index(4)           # find index
a.count(1)           # count occurrences
a.sort()             # in-place
sorted(a)            # returns new list
a.sort(reverse=True)

Dicts & Sets

Hash tables — O(1) average insert/delete/lookup. The key to most frequency problems.

dictsetdefaultdictCounter Dict, Set, defaultdict & Counter
What & Why
Dicts and sets are hash tables — O(1) average for insert, delete, lookup. Dicts preserve insertion order (Python 3.7+). Sets are unordered and hold only unique elements.

defaultdict: Like a regular dict but never raises KeyError — it creates a default value on missing key. defaultdict(int) starts at 0, defaultdict(list) starts at [].

Counter: Subclass of dict, counts hashable objects. Great for frequency maps and anagram problems.

Set use cases
  • O(1) "seen" check in graph traversal
  • Deduplicate: list(set(arr))
  • Find intersection/difference of two collections

Functions

First-class objects, *args/**kwargs, lambda, and the mutable default trap.

def*args / **kwargslambda Function Signatures & Gotchas
What & Why
Functions are first-class objects in Python — you can pass them around, assign them to variables, return them. This enables functional patterns like sorted(arr, key=fn).

*args vs **kwargs
  • *args — collects extra positional args as a tuple
  • **kwargs — collects extra keyword args as a dict
  • Call with: fn(*my_list) to unpack a list as args
The mutable default trap: default argument values are evaluated once at function definition, not on each call. A mutable default like def f(x=[]) will accumulate state across calls. Always use None as default for mutable types.
⚠️ Mutable default trap: default argument values are evaluated once at definition, not per call. def f(x=[]) accumulates state across calls. Always use None as default for mutable types.
args / kwargs / lambda

    return f"{greeting}, {name}"

def total(*args):          # tuple
    return sum(args)

def info(**kwargs):        # dict
    for k, v in kwargs.items(): ...

double = lambda x: x * 2
add    = lambda x, y: x + y
mutable default gotcha
python
# WRONG — list shared across all calls!

    lst.append(1)
    return lst

# CORRECT
def good(lst=None):
    if lst is None:
        lst = []
    lst.append(1)
    return lst

OOP Basics

Classes, dunder methods, inheritance, and @dataclass for quick node/point classes.

class__init____lt__@dataclass Classes, Dunders & Dataclass
What & Why
Classes bundle data and behavior. In interviews you'll need this for linked list nodes, tree nodes, or when asked to design a class.

Key dunder methods
  • __init__: constructor, called on MyClass()
  • __repr__: unambiguous string representation — used in the REPL and debugging
  • __str__: human-readable, used by print()
  • __eq__: enables == comparison

Two Pointers

Avoid O(n²) nested loops by moving two indices intelligently through the array.

l / rslow / fastO(n) timeO(1) space Two Pointer Patterns
Core idea
Use two index variables that move through the array to avoid the O(n²) nested loop. There are two flavors: opposite ends (l and r converging) and same direction (slow/fast pointer).

Opposite ends — when to use
  • Two Sum on a sorted array
  • Container With Most Water
  • Check if palindrome
  • 3Sum (fix one, two-pointer the rest)
Same direction — when to use
  • Remove duplicates / filter in-place
  • Cycle detection in linked list (Floyd's)
  • Partition: Dutch National Flag (3-way sort)
Complexity: O(n) time, O(1) space.
opposite ends (sorted array)
python · Two Sum Sorted
def two_sum_sorted(arr, target):
    l, r = 0, len(arr) - 1
    while l < r:
        s = arr[l] + arr[r]
        if s == target:
            return l, r
        elif s < target:
            l += 1
        else:
            r -= 1
    return -1, -1
same direction (fast & slow)
python · Remove Duplicates In-Place
# LC 26 — Remove Duplicates from Sorted Array
def remove_dups(arr):
    slow = 0
    for fast in range(1, len(arr)):
        if arr[fast] != arr[slow]:
            slow += 1
            arr[slow] = arr[fast]
    return slow + 1  # new length

Sliding Window

Maintain a contiguous subarray window — O(n) instead of O(n²).

fixed windowvariable windowO(n) time Fixed & Variable Size Windows
Core idea
Maintain a contiguous subarray/substring "window" with two pointers (l, r). Expand r to include new elements, shrink l when a constraint is violated. Avoids recalculating from scratch each step — O(n) instead of O(n²).

Fixed window: window size k is constant. Slide by adding new element and dropping leftmost (arr[i] - arr[i-k]).

Variable window: expand until invalid, then shrink from left. Track the maximum (or minimum) valid window seen.

Classic problems
  • Longest substring without repeating characters
  • Minimum window substring (use Counter)
  • Max sum subarray of size k
  • Longest subarray with sum ≤ k
  • At most k distinct characters
fixed size window
python · Max Sum Subarray Size k
def max_sum_k(arr, k):
    window = sum(arr[:k])
    best   = window
    for i in range(k, len(arr)):
        window += arr[i] - arr[i-k]  # slide
        best = max(best, window)
    return best
variable size window
python · Longest Subarray sum ≤ target
def longest(arr, target):
    l = cur = best = 0
    for r in range(len(arr)):
        cur += arr[r]          # expand right
        while cur > target:
            cur -= arr[l]      # shrink left
            l += 1
        best = max(best, r - l + 1)
    return best

Binary Search

Halve the search space each step — O(log n). Works on arrays AND answer spaces.

l <= rmid = (l+r)//2bisectO(log n) Classic & Answer-Space Binary Search
Core idea
Halve the search space each step. Requires the array to be sorted or the answer space to be monotonic (a predicate that flips from false to true at exactly one point).

Classic template pitfalls
  • Use (l + r) // 2 not (l + r) / 2
  • Loop condition: while l <= r for exact match; while l < r for leftmost/rightmost position
  • After the loop, check arr[l] — it's the answer boundary
Search on answer space: if the question is "minimum X such that condition(X) is true" — binary search on X directly (not on an array). Works when condition is monotonic.

Classic problems: find peak element, search rotated array, koko eating bananas, capacity to ship packages.
classic template
python · exact match
def binary_search(arr, target):
    l, r = 0, len(arr) - 1
    while l <= r:
        mid = (l + r) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            l = mid + 1
        else:
            r = mid - 1
    return -1
bisect (stdlib) & answer-space
python
import bisect

a = [1, 3, 5, 7, 9]
bisect.bisect_left(a, 5)   # 2  (first ≥5)
bisect.bisect_right(a, 5)  # 3  (first >5)
bisect.insort(a, 6)        # insert sorted

# "find leftmost feasible" template
l, r = 0, n
while l < r:
    mid = (l + r) // 2
    if feasible(mid): r = mid
    else:             l = mid + 1
# l is the answer

BFS — Breadth-First Search

Level-by-level exploration. Guarantees shortest path in unweighted graphs.

dequevisited set4-directionalShortest Path Graph BFS & Grid BFS
Core idea
Explore nodes level by level using a queue (FIFO). BFS guarantees the shortest path in an unweighted graph. Use deque for O(1) popleft — a regular list's pop(0) is O(n).

Template skeleton: (1) push start into queue + mark visited, (2) while queue: pop → process → push unvisited neighbors.

Classic problems
  • Shortest path in a maze / grid
  • Level-order traversal of a tree
  • Word Ladder (graph on word edits)
  • Rotting Oranges (multi-source BFS)
  • Number of islands (flood fill)
Multi-source BFS: push all starting nodes at once before the loop. Useful when you have multiple "origins" (e.g. all rotten oranges).
⚠️ Always use deque for BFS, never list. list.pop(0) is O(n); deque.popleft() is O(1).
graph BFS (shortest path)
python
from collections import deque

def bfs(graph, start):
    visited = {start}
    q = deque([(start, 0)])   # (node, dist)
    while q:
        node, dist = q.popleft()
        for nei in graph[node]:
            if nei not in visited:
                visited.add(nei)
                q.append((nei, dist + 1))
    return dist
grid BFS (4-directional)
python
DIRS = [(0,1),(0,-1),(1,0),(-1,0)]

def bfs_grid(grid, sr, sc):
    rows, cols = len(grid), len(grid[0])
    q = deque([(sr, sc, 0)])
    seen = {(sr, sc)}
    while q:
        r, c, d = q.popleft()
        for dr, dc in DIRS:
            nr, nc = r+dr, c+dc
            if (0 <= nr < rows and 0 <= nc < cols
                    and (nr, nc) not in seen):
                seen.add((nr, nc))
                q.append((nr, nc, d+1))

DFS & Backtracking

Go deep before backtracking. Powers tree traversal, graph exploration, and combinatorics.

recursiveiterative stackbacktrackinginorder DFS Templates & Backtracking
Core idea
Go as deep as possible before backtracking. Uses the call stack (recursive) or an explicit stack (iterative). DFS does NOT guarantee shortest path — use BFS for that.

Backtracking is DFS + undo. The key pattern: choose → explore → unchoose. You must undo the choice before trying the next one — this is the path.pop() step that people forget.

Tree traversal orders
  • Inorder (left → node → right): gives sorted order for BST
  • Preorder (node → left → right): serialize a tree
  • Postorder (left → right → node): delete a tree, evaluate expression tree
Classic problems: subsets, permutations, combination sum, N-Queens, Sudoku solver, path sum in tree, connected components.
⚠️ Don't forget path.pop() — the "undo" step in backtracking. Without it, choices bleed into sibling branches.
recursive DFS (graph)
python
def dfs(graph, node, visited=None):
    if visited is None:
        visited = set()
    visited.add(node)
    for nei in graph[node]:
        if nei not in visited:
            dfs(graph, nei, visited)
    return visited
backtracking template
python · choose → explore → unchoose
def solve(path, choices):
    if is_done(path):
        results.append(path[:])  # snapshot!
        return
    for c in choices:
        if is_valid(c):
            path.append(c)       # choose
            solve(path, choices) # explore
            path.pop()           # unchoose ←
tree DFS — inorder
python
def inorder(root, res=[]):
    if root:
        inorder(root.left, res)
        res.append(root.val)   # ← inorder
        inorder(root.right, res)
    return res

# preorder:  visit BEFORE recurse
# postorder: visit AFTER  recurse
iterative DFS (explicit stack)
python
def dfs_iter(graph, start):
    stack = [start]
    visited = {start}
    while stack:
        node = stack.pop()
        for nei in graph[node]:
            if nei not in visited:
                visited.add(nei)
                stack.append(nei)

Heap / Priority Queue

Always-sorted extraction in O(log n). Min-heap by default in Python via heapq.

heapqmin-heap-val trickO(log n) push/pop heapq — Min-Heap & Max-Heap Trick
Core idea
A heap is a complete binary tree that satisfies the heap property: the parent is always smaller than its children (min-heap). Python's heapq is a min-heap. The minimum is always at index 0.

Complexities: push/pop = O(log n), peek = O(1), heapify = O(n).

Max-heap trick: Python has no max-heap. Negate values to simulate one: push -val, pop and negate back.

Classic problems
  • Kth largest / smallest element
  • Top K frequent elements
  • Merge K sorted lists
  • Running median (two heaps: max-heap for lower half, min-heap for upper half)
  • Dijkstra's shortest path
  • Task scheduler
heapq (min-heap)
python
import heapq

h = []
heapq.heappush(h, 5)
heapq.heappush(h, 1)
heapq.heappush(h, 3)

heapq.heappop(h)        # → 1 (min)
h[0]                    # peek min  O(1)

# heapify an existing list
arr = [3, 1, 4, 1, 5]
heapq.heapify(arr)      # O(n)

# k largest / smallest
heapq.nlargest(k, arr)
heapq.nsmallest(k, arr)
max-heap trick & Dijkstra
python
# Max-heap: negate to simulate
heapq.heappush(h, -val)
max_val = -heapq.heappop(h)

# Push tuples (sorted by first element)
heapq.heappush(h, (priority, item))
pri, item = heapq.heappop(h)

# Dijkstra sketch
dist = {start: 0}
pq = [(0, start)]
while pq:
    d, u = heapq.heappop(pq)
    for v, w in graph[u]:
        nd = d + w
        if nd < dist.get(v, float('inf')):
            dist[v] = nd
            heapq.heappush(pq, (nd, v))

Prefix Sum

Precompute running sums for O(1) subarray queries. Combine with a hash map for subarray-sum-equals-k.

prefix[r+1] - prefix[l]hash map trickO(1) query Prefix Sum & Subarray Sum = k
Core idea
Precompute a running sum array so any subarray sum arr[l..r] can be answered in O(1): prefix[r+1] - prefix[l]. Build is O(n), each query is O(1).

Hash map trick: to count subarrays with sum exactly k, track how many times each prefix sum has occurred. If prefix[j] - prefix[i] == k, the subarray i+1..j sums to k. Walking right, you just need to look up seen[current_prefix - k].

Classic problems
  • Range sum queries (2D prefix sum for matrices)
  • Subarray sum equals k
  • Contiguous array (equal 0s and 1s — map 0→-1)
  • Product of array except self (prefix + suffix products)
2D prefix sum: p[i][j] = grid[i][j] + p[i-1][j] + p[i][j-1] - p[i-1][j-1]
build & query
python
def build_prefix(arr):
    prefix = [0] * (len(arr) + 1)
    for i, v in enumerate(arr):
        prefix[i+1] = prefix[i] + v
    return prefix

# sum of arr[l..r] inclusive:
# prefix[r+1] - prefix[l]
subarray sum = k (hash map)
python · LC 560 — classic O(n) trick
from collections import defaultdict

def subarray_sum_k(arr, k):
    count = prefix = 0
    seen = defaultdict(int)
    seen[0] = 1            # empty prefix
    for x in arr:
        prefix += x
        count += seen[prefix - k]  # ← key lookup
        seen[prefix] += 1
    return count

# prefix[j] - prefix[i] = k
# → seen[prefix - k] counts matching i's
