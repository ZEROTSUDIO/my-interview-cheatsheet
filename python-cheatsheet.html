Basic I/O & Type Casting

Membaca input, mencetak output, dan konversi tipe data — langkah awal setiap soal coding.

input()print()map()ord / chr Reading Input & Type Casting (Membaca Input & Konversi Tipe)
Apa & Mengapa
Setiap masalah coding/interview dimulai dengan membaca input dan mencetak hasil. Fungsi input() di Python selalu mengembalikan string — jadi kamu harus melakukan type cast. Menggunakan map(int, input().split()) adalah cara tercepat membaca angka yang dipisahkan spasi dalam satu baris.

Penggunaan Umum dalam Interview
  • Membaca satu integer: n = int(input())
  • Membaca 2 integer dalam 1 baris: a, b = map(int, input().split())
  • Membaca n baris menjadi list: [int(input()) for _ in range(n)]
  • Format output: f-string adalah cara paling rapi — f"{val:.2f}" untuk angka desimal
Kasus Khusus yang Perlu Diingat
ord('a') = 97, chr(97) = 'a' — sangat berguna untuk trik indeks huruf seperti ord(c) - ord('a').

name = input("Masukkan nama: ")
n    = int(input())           # konversi string ke int langsung
a, b = map(int, input().split()) # baca 2 angka sekaligus

print(f"Halo, {name}!")
print(a, b, sep=", ", end="\n")

Control Flow (Percabangan & Perulangan)

if/elif/else, perulangan for/while, ternary operator, dan trik range() — pondasi utama logika Python.

if / eliffor / whilerange()ternary Conditionals, Loops & Range Tricks (Kondisional & Perulangan)
Apa & Mengapa
Python menggunakan indentasi (spasi) untuk menentukan blok kode — tanpa kurung kurawal {}. Perbedaan penting dengan bahasa lain: tidak ada operator i++, gunakan i += 1. Klausa else pada perulangan hanya berjalan jika perulangan TIDAK terhenti oleh break.

Trik Penggunaan range()
  • range(n) → dari 0 hingga n-1
  • range(a, b) → dari a hingga b-1
  • range(n-1, -1, -1) → dari n-1 mundur ke 0 (iterasi terbalik)
  • range(0, n, 2) → langkah lompat 2 indeks
Ternary Operator: x if kondisi else y — penulisan if/else singkat dalam 1 baris yang lebih bersih.

Strings (Manipulasi String)

Tipe data immutable — teknik slicing, metode bawaan, f-string, dan pola join.

str methodsslicingf-strings"".join() String Methods, Slicing & Building (Metode & Manipulasi Teks)
Apa & Mengapa
String di Python bersifat immutable — karakter di dalamnya tidak bisa diubah langsung. Setiap "perubahan" membuat string baru. Hal ini memicu masalah performa: menggabungkan string dengan += di dalam loop memakan waktu O(n²). Gunakan list dan "".join() untuk O(n).

Pola Penggunaan Populer di Interview
  • Cek Palindrom: s == s[::-1]
  • Cek Anagram: sorted(s) == sorted(t) atau gunakan Counter
  • Pisah berdasarkan spasi: s.split() (menangani spasi ganda secara otomatis)
  • Frekuensi karakter: Counter(s)
  • Indeks huruf 0-25: ord(c) - ord('a')
Teknik Slicing: s[start:stop:step]. Nilai step negatif membalikkan string. Indeks di luar batas tidak menyebabkan error crash.
⚠️ String bersifat immutable. Menggabungkan string dengan += di dalam loop adalah O(n²). Gunakan list dan "".join(buf) yang jauh lebih cepat — O(n).

Lists & Arrays

Array dinamis — struktur data paling fleksibel. Append/pop O(1), list comprehension, dan sorting.

list opscomprehensionsort / keydeque List Operations, Comprehensions & Sorting (Operasi & Pengurutan List)
Apa & Mengapa
List di Python adalah array dinamis. Menambah/menghapus dari ujung (append/pop) beroperasi dalam O(1). Namun, pop(0) atau insert di depan beroperasi dalam O(n) — gunakan deque untuk antrean (queue). Pengurutan (sort) menggunakan Timsort berkecepatan O(n log n).

Pola Penting di Coding Interview
  • Inisialisasi grid 2D: [[0]*cols for _ in range(rows)] — hindari [[0]*cols]*rows karena mereferensikan memori yang sama!
  • Ambil elemen terakhir: arr[-1]
  • Balikkan list: arr.reverse() (in-place) atau arr[::-1] (salinan baru)
  • Sort dengan kriteria khusus: arr.sort(key=lambda x: x[1])
  • Ratakan list 2D (flatten): [x for row in matrix for x in row]
enumerate vs range(len): selalu utamakan for i, v in enumerate(arr) daripada for i in range(len(arr)) agar lebih clean.
⚠️ Operasi pop(0) memerlukan O(n). Untuk struktur data antrean (queue), gunakan collections.deque dengan fungsi popleft() yang O(1).

Dicts & Sets (Dictionary & Himpunan)

Hash tables — rata-rata O(1) untuk pencarian, penambahan, dan penghapusan. Kunci utama persoalan frekuensi.

dictsetdefaultdictCounter Dict, Set, defaultdict & Counter (Hash Map & Set)
Apa & Mengapa
Dict dan set diimplementasikan menggunakan Hash Table — pencarian, insert, dan delete rata-rata O(1). Dict menjaga urutan penambahan elemen (Python 3.7+). Set bersifat unik dan tidak berurutan.

defaultdict: Seperti dict biasa tetapi tidak pernah melempar error KeyError — otomatis membuat nilai bawaan saat key belum ada. defaultdict(int) mulai dari 0, defaultdict(list) mulai dari [].

Counter: Subclass dari dict untuk menghitung frekuensi objek. Sangat cocok untuk masalah frekuensi dan anagram.

Kegunaan Set
  • Pengecekan node yang telah dikunjungi (seen/visited) secara O(1) pada pencarian graf
  • Menghapus duplikat: list(set(arr))
  • Mencari irisan (intersection) dan selisih (difference) dua himpunan

Functions (Fungsi & Lambda)

First-class objects, *args/**kwargs, fungsi anonim lambda, dan jebakan mutable default.

def*args / **kwargslambda Function Signatures & Gotchas (Sintaks & Jebakan Fungsi)
Apa & Mengapa
Fungsi di Python adalah first-class objects — bisa dikirim sebagai argumen, disimpan dalam variabel, atau dikembalikan dari fungsi lain. Hal ini mendukung pemrograman fungsional seperti sorted(arr, key=fn).

*args vs **kwargs
  • *args — menampung argumen posisi tambahan menjadi tuple
  • **kwargs — menampung argumen kata kunci (keyword) tambahan menjadi dict
  • Panggilan: fn(*my_list) membongkar isi list sebagai argumen terpisah
Jebakan Mutable Default Value: Nilai bawaan argumen dievaluasi hanya sekali saat fungsi didefinisikan, bukan setiap kali dipanggil. Argumen bawaan mutable seperti def f(x=[]) akan menyimpan status dari pemanggilan sebelumnya. Selalu gunakan None sebagai default tipe data mutable.
⚠️ Jebakan Mutable Default: Nilai bawaan argumen dievaluasi sekali saat definisi. Fungsi def f(x=[]) menumpuk data antar pemanggilan. Selalu gunakan None sebagai nilai awal tipe data mutable!

Two Pointers (Dua Pointer)

Hindari perulangan bersarang O(n²) dengan menggeser dua indeks array secara cerdas.

l / rslow / fastO(n) timeO(1) space Two Pointer Patterns (Pola Konvergen & Fast/Slow)
Gagasan Utama
Gunakan dua variabel indeks yang bergerak melewati array untuk menghindari perulangan bersarang (nested loop) berkecepatan O(n²). Ada dua pendekatan utama: arah berlawanan (l dan r saling mendekat) dan searah (slow/fast pointer).

Arah Berlawanan (Opposite Ends) — Kapan Digunakan:
  • Two Sum pada array terurut
  • Container With Most Water
  • Memeriksa string palindrom
  • 3Sum (kunci 1 angka, gunakan two pointer untuk sisanya)
Searah (Slow & Fast) — Kapan Digunakan:
  • Menghapus elemen duplikat secara in-place
  • Deteksi siklus pada Linked List (Algoritma Floyd)
  • Partisi array (Dutch National Flag sort)
Kompleksitas: Waktu O(n), Memori Tambahan O(1).
arah berlawanan (array terurut)
python · Two Sum Sorted
def two_sum_sorted(arr, target):
    l, r = 0, len(arr) - 1
    while l < r:
        s = arr[l] + arr[r]
        if s == target:
            return l, r
        elif s < target:
            l += 1  # butuh jumlah lebih besar
        else:
            r -= 1  # butuh jumlah lebih kecil
    return -1, -1
searah (fast & slow pointer)
python · Hapus Duplikat In-Place
# LC 26 — Hapus Duplikat dari Array Terurut
def remove_dups(arr):
    slow = 0
    for fast in range(1, len(arr)):
        if arr[fast] != arr[slow]:
            slow += 1
            arr[slow] = arr[fast]
    return slow + 1  # panjang array baru

Sliding Window (Jendela Geser)

Jaga jendela sub-array beruntun tetap aktif — O(n) alih-alih perulangan O(n²).

fixed windowvariable windowO(n) time Fixed & Variable Size Windows (Jendela Ukuran Tetap & Dinamis)
Gagasan Utama
Pertahankan rentang "jendela" sub-array/sub-string berurutan menggunakan dua pointer (l, r). Perluas r ke kanan untuk memasukkan elemen baru, ciutkan l dari kiri jika batas kriteria terlampaui. Menghindari penghitungan ulang dari awal pada setiap langkah — O(n) alih-alih O(n²).

Jendela Ukuran Tetap (Fixed Window): Ukuran jendela k bersifat konstan. Geser dengan menambah elemen baru dan mengurangi elemen paling kiri (arr[i] - arr[i-k]).

Jendela Ukuran Dinamis (Variable Window): Perluas r sampai kondisi tidak valid, lalu ciutkan l dari kiri. Catat ukuran jendela valid maksimum (atau minimum).

Soal Klasik Interview:
  • Substring terpanjang tanpa karakter berulang
  • Minimum window substring (gunakan Counter)
  • Jumlah maksimum sub-array berukuran k
  • Sub-array terpanjang dengan jumlah elemen ≤ k
  • Paling banyak k karakter unik
jendela ukuran tetap (fixed window)
python · Jumlah Maksimum Subarray Ukuran k
def max_sum_k(arr, k):
    window = sum(arr[:k])  # jumlah awal k elemen
    best   = window
    for i in range(k, len(arr)):
        window += arr[i] - arr[i-k]  # geser jendela
        best = max(best, window)
    return best
jendela ukuran dinamis (variable window)
python · Subarray Terpanjang sum ≤ target
def longest(arr, target):
    l = cur = best = 0
    for r in range(len(arr)):
        cur += arr[r]          # perluas ke kanan
        while cur > target:
            cur -= arr[l]      # ciutkan dari kiri
            l += 1
        best = max(best, r - l + 1)
    return best

Binary Search (Pencarian Biner)

Bagi dua ruang pencarian pada setiap langkah — O(log n). Berlaku untuk array terurut DAN ruang jawaban monoton.

l <= rmid = (l+r)//2bisectO(log n) Classic & Answer-Space Binary Search (Pencarian Biner Array & Ruang Jawaban)
Gagasan Utama
Pangkas separuh ruang pencarian pada setiap iterasi. Syaratnya: array harus dalam keadaan terurut atau ruang jawaban bersifat monotonik (predikat yang berubah dari false ke true tepat pada satu titik).

Poin Penting Template Klasik
  • Gunakan (l + r) // 2 (pembagian bulat) BUKAN (l + r) / 2
  • Kondisi perulangan: while l <= r untuk pencarian cocok persis; while l < r untuk mencari batas kiri/kanan
  • Setelah perulangan selesai, periksa nilai pada indeks l
Pencarian Biner pada Ruang Jawaban (Search on Answer Space): Jika pertanyaan berupa "cari X terkecil sehingga kondisi(X) bernilai true" — lakukan binary search langsung pada nilai X. Sangat cocok jika fungsi kondisi bersifat monoton.

Soal Klasik: Koko Eating Bananas, Kapasitas Pengiriman Paket, Cari Elemen Puncak (Peak), Search rotated array.
template klasik (cocok persis)
python · Exact Match
def binary_search(arr, target):
    l, r = 0, len(arr) - 1
    while l <= r:
        mid = (l + r) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            l = mid + 1
        else:
            r = mid - 1
    return -1
modul bisect & search pada ruang jawaban
python
import bisect

a = [1, 3, 5, 7, 9]
bisect.bisect_left(a, 5)   # 2  (posisi pertama ≥ 5)
bisect.bisect_right(a, 5)  # 3  (posisi pertama > 5)
bisect.insort(a, 6)        # sisipkan agar tetap terurut

# Template "Cari Nilai Minimum yang Memenuhi Syarat"
l, r = 0, n
while l < r:
    mid = (l + r) // 2
    if feasible(mid): r = mid
    else:             l = mid + 1
# l adalah jawaban terkecil

BFS — Breadth-First Search (Pencarian Melebar)

Eksplorasi tingkat demi tingkat (level order). Menjamin jalur terpendek pada graf tanpa bobot.

dequevisited set4-directionalShortest Path Graph BFS & Grid BFS (BFS pada Graf & Matriks Grid)
Gagasan Utama
Jelajahi node tingkat demi tingkat menggunakan Antrean / Queue (FIFO). BFS menjamin jarak/jalur terpendek pada graf tanpa bobot. Wajib gunakan deque untuk operasi popleft() O(1) — menggunakan pop(0) pada list biasa berkecepatan lambat O(n).

Alur Template BFS: (1) Masukkan node awal ke queue + tandai visited, (2) Selama queue tidak kosong: pop -> proses node -> masukkan semua tetangga yang belum dikunjungi.

Soal Klasik Interview:
  • Jalur terpendek pada Labirin / Matriks Grid
  • Level-order traversal pada Tree (Pohon)
  • Word Ladder (Graf perubahan kata)
  • Rotting Oranges (Multi-source BFS)
  • Menghitung jumlah pulau (Flood Fill)
Multi-source BFS: Masukkan semua node sumber awal sekaligus ke dalam queue sebelum perulangan utama dimulai (contoh: semua jeruk busuk awal).
⚠️ Wajib gunakan collections.deque untuk BFS, BUKAN list biasa. Fungsi list.pop(0) memakan O(n); sedangkan deque.popleft() beroperasi O(1).
BFS graf (jalur terpendek)
python
from collections import deque

def bfs(graph, start):
    visited = {start}
    q = deque([(start, 0)])   # (node, jarak)
    while q:
        node, dist = q.popleft()
        for nei in graph[node]:
            if nei not in visited:
                visited.add(nei)

DFS & Backtracking (Pencarian Mendalam & Melacak Balik)

        
Jelajahi ke cabang terdalam sebelum melacak balik (backtrack). Digunakan untuk penelusuran pohon, eksplorasi graf, dan kombinatorika.

      

    


    

      

        

          recursiveiterative stackbacktrackinginorder
          DFS Templates & Backtracking (Pola Rekursif, Stack & Backtrack)
        

        
      

      

        
        

          Gagasan Utama

          Masuk ke cabang paling dalam sebelum kembali (backtrack). Menggunakan Call Stack (rekursif) atau Stack manual (iteratif). DFS TIDAK menjamin jalur terpendek — gunakan BFS jika mencari jalur terpendek.


          Backtracking adalah DFS + pembatalan langkah (undo). Alur utamanya: pilih → eksplorasi → batalkan pilihan. Kamu wajib membatalkan pilihan sebelum mencoba cabang berikutnya — langkah ini adalah path.pop() yang sering terlupakan.


          Urutan Penelusuran Pohon (Tree Traversal)
          
    
            
  • Inorder (kiri → node → kanan): menghasilkan urutan terurut pada BST
    • 
            
  • Preorder (node → kiri → kanan): serialisasi struktur pohon
    • 
            
  • Postorder (kiri → kanan → node): penghapusan pohon atau evaluasi ekspresi pohon
    • 
          

          Soal Klasik Interview: Subset, Permutasi, Combination Sum, N-Queens, Sudoku Solver, Path Sum pada Tree.
        

        
⚠️ Jangan lupa langkah path.pop() — langkah "batalkan pilihan" pada backtracking. Tanpa langkah ini, pilihan cabang sebelumnya akan merembet ke cabang tetangga.


        

          

            
DFS rekursif (graf)

            

              
python

              
def dfs(graph, node, visited=None):
    if visited is None:
        visited = set()
    visited.add(node)
    for nei in graph[node]:
        if nei not in visited:
            dfs(graph, nei, visited)
    return visited

def solve(path, choices):
    if is_done(path):

def inorder(root, res=[]):
    if root:
        inorder(root.left, res)
        res.append(root.val)   # ← urutan inorder
        inorder(root.right, res)
    return res

def dfs_iter(graph, start):
    stack = [start]
    visited = {start}
    while stack:
        node = stack.pop()

            if nei not in visited:
                visited.add(nei)
                stack.append(nei)

Heap / Priority Queue (Antrean Prioritas)

        
Ekstraksi nilai minimum/maksimum secara terurut dalam O(log n). Python menyediakan Min-Heap secara default lewat modul heapq.

      

    


    

      

        

          heapqmin-heap-val trickO(log n) push/pop
          heapq — Min-Heap & Trik Max-Heap
        

        
      

      

        
        

          Gagasan Utama

          Heap adalah Binary Tree lengkap yang selalu mempertahankan elemen terkecil di posisi paling atas / indeks 0 (Min-Heap pada Python heapq).


          Kompleksitas: push/pop = O(log n), intip nilai terkecil (h[0]) = O(1), ubah list ke heap (heapify) = O(n).


          Trik Max-Heap: Python tidak memiliki pustaka resmi Max-Heap. Balikkan tanda minus (-val) saat push, lalu balikkan kembali tanda minusnya saat pop.

Prefix Sum (Jumlah Awalan)

        
Pra-hitung jumlah kumulatif array untuk query rentang sub-array berkecepatan O(1). Gabungkan dengan Hash Map untuk pencarian sub-array ber-jumlah k.

      

    


    

      

        

          prefix[r+1] - prefix[l]hash map trickO(1) query
          Prefix Sum & Subarray Sum = k (Trik Kumulatif & Hash Map)
        

        
      

      

        
        

          Gagasan Utama

          Pra-hitung array jumlah kumulatif sehingga total nilai sub-array arr[l..r] dapat dijawab instan O(1): prefix[r+1] - prefix[l]. Pembuatan awal O(n), query O(1).


          Trik Hash Map (Subarray Sum Equals K): Untuk menghitung berapa banyak sub-array yang tepat berjumlah k, catat frekuensi kemunculan setiap prefix sum pada hash map. Jika prefix[j] - prefix[i] == k, maka sub-array i+1..j berjumlah k.


          Soal Klasik Interview:
          
    
            
  • Query jumlah rentang (Range sum query 1D & 2D)
    • 
            
  • Subarray sum equals k (LC 560)
    • 
            
  • Array dengan jumlah angka 0 dan 1 seimbang (ubah 0 jadi -1)
    • 
            
  • Product of array except self (prefix & suffix product)
    • 
          

          Prefix Sum Matriks 2D: p[i][j] = grid[i][j] + p[i-1][j] + p[i][j-1] - p[i-1][j-1]
        


        

          

            
pembuatan & query rentang

            

              
python

              
def build_prefix(arr):
    prefix = [0] * (len(arr) + 1)
    for i, v in enumerate(arr):
        prefix[i+1] = prefix[i] + v
    return prefix

# total jumlah arr[l..r] inklusif:
# prefix[r+1] - prefix[l]

            

          

          

            
subarray sum = k (pola hash map)

            

              
python · LC 560 — trik klasik O(n)

              
from collections import defaultdict

def subarray_sum_k(arr, k):
    count = prefix = 0
    seen = defaultdict(int)
    seen[0] = 1            # awalan kosong
    for x in arr:
        prefix += x
        count += seen[prefix - k]  # ← cari kecocokan prefix awal
        seen[prefix] += 1
    return count

# prefix[j] - prefix[i] = k
# → seen[prefix - k] menghitung berapa banyak i yang cocok
