Instruksi Umum di Soal

Kata-kata kunci yang sering muncul pada deskripsi masalah LeetCode & pertanyaan interview.

Given pembuka soal Diberikan

Kata pembuka paling sering muncul di soal. Semua yang disebut setelah kata ini adalah fakta atau input yang sudah pasti benar dan wajib kamu pakai apa adanya, bukan sesuatu yang perlu dipertanyakan atau dibuktikan.

Contoh Penggunaan
Given an array of integers nums, return the two indices...
Diberikan array bilangan bulat nums, kembalikan dua indeksnya...
Return kata kerja Mengembalikan (nilai)

Nilai yang harus keluar dari fungsimu lewat statement return, bukan lewat print atau console.log. Ini nilai yang dicek sistem untuk menentukan jawabanmu benar atau salah.

Contoh Penggunaan
return the sum of the two numbers
kembalikan (sebagai output fungsi) hasil penjumlahan dua angka itu
Input / Output istilah Masukan / Keluaran

Input adalah data yang diterima fungsi lewat parameter. Output adalah data yang dihasilkan atau dikembalikan. Selalu cek tipe data dan bentuk keduanya sebelum mulai menulis kode.

Contoh Penggunaan
Input: nums = [2,7,11,15], target = 9. Output: [0,1]
array nums dan angka target itu masukan; array [0,1] itu keluaran yang diharapkan
Implement / Write a function instruksi Buat / tulis sebuah fungsi

Perintah langsung untuk mulai coding. Biasanya kamu sudah dikasih nama fungsi dan parameternya (disebut signature) — jangan diubah namanya, karena sistem penilaian mengecek nama itu persis.

Contoh Penggunaan
Implement a function twoSum(nums, target)
buat fungsi bernama twoSum yang menerima nums dan target, jangan diganti jadi nama lain
Determine whether / Check if instruksi Tentukan apakah / Cek apakah

Tandanya jawaban akhir yang diminta berupa boolean, yaitu true atau false, bukan angka atau array. Sering bikin orang salah fokus mencari "nilai"-nya padahal yang diminta cuma jawaban ya atau tidak.

Contoh Penggunaan
Determine whether the string is a palindrome
tentukan apakah string itu palindrom — jawabannya cuma true atau false
You may assume / Assume that batasan Kamu boleh anggap

Kalimat yang membebaskan kamu dari mengecek kondisi tertentu. Kalau soal menyebut ini, jangan buang waktu menulis validasi untuk kondisi yang sudah dijamin itu.

Contoh Penggunaan
You may assume that each input has exactly one solution
kamu boleh anggap selalu ada satu jawaban — tidak perlu menangani kasus "tidak ada solusi"
Constraints batasan Batasan

Bagian paling penting yang sering terlewat karena grogi. Isinya ukuran maksimum input dan rentang nilai — ini yang memberitahu kamu seberapa efisien solusi yang dibutuhkan.

Contoh Penggunaan
1 <= nums.length <= 10^5
array bisa sampai 100.000 elemen, jadi solusi dengan dua loop bersarang kemungkinan besar akan terlalu lambat
Edge case istilah Kasus khusus/ekstrem

Input yang tampak "aneh" tapi tetap valid: array kosong, satu elemen saja, semua elemen sama, angka negatif, atau nol. Interviewer sering sengaja menunggu kamu menyebut ini sendiri sebelum mulai coding.

Contoh Penggunaan
what if the array is empty?
bagaimana kalau array-nya kosong? — ini pertanyaan edge case yang wajib kamu pikirkan sendiri
In-place teknik Diubah langsung di tempat

Memodifikasi data asli tanpa membuat struktur data baru yang memakan memori tambahan. Biasanya diminta secara eksplisit di soal array atau sorting.

Contoh Penggunaan
reverse the array in-place
balik urutan array itu langsung di array yang sama, jangan bikin array baru untuk menampung hasilnya
Mutate kata kerja Mengubah isi (data asli)

Mirip dengan in-place — mengubah isi variabel atau objek aslinya secara langsung, bukan membuat salinan baru. Penting dibedakan dari "kembalikan array baru".

Contoh Penggunaan
the function should mutate the input array
fungsi ini harus langsung mengubah isi array input-nya, bukan membuat array baru lalu di-return
Traverse / Iterate kata kerja Menjelajah / Mengulang

Melewati setiap elemen satu per satu, biasanya menggunakan loop (for/while) atau rekursi. "Traverse the tree" berarti kunjungi tiap node yang ada di pohon itu.

Contoh Penggunaan
traverse the linked list until you reach the end
jelajahi setiap node di linked list satu per satu sampai ketemu node terakhir
Recursive / Base case konsep Rekursif / Kondisi dasar

Recursive berarti fungsi memanggil dirinya sendiri untuk menyelesaikan versi lebih kecil dari masalah yang sama. Base case adalah kondisi berhenti — tanpa ini, rekursi akan berjalan tanpa henti dan program crash.

Contoh Penggunaan
if (n === 0) return 1; // base case
kalau n sudah 0, langsung berhenti dan kembalikan 1 — ini yang mencegah fungsi memanggil dirinya sendiri selamanya
Optimal / Optimize kata sifat Paling efisien / Mengoptimalkan

Solusi tercepat atau paling hemat memori yang memungkinkan untuk masalah itu. Kalau diminta "can you optimize this", artinya solusi kamu sekarang masih bisa dibuat lebih cepat.

Contoh Penggunaan
can you find a more optimal solution?
bisa tidak mencari solusi yang lebih efisien dari yang tadi?
Brute force teknik Cara paling sederhana

Solusi paling mudah dipikirkan tapi biasanya paling lambat, karena mengecek semua kemungkinan satu per satu. Wajar dijadikan langkah pertama saat interview sebagai jawaban aman sebelum dioptimasi.

Contoh Penggunaan
start with a brute force solution first
mulai dulu pakai cara paling sederhana, nanti dioptimasi belakangan
Time Limit Exceeded (TLE) istilah Waktu eksekusi melebihi batas

Muncul kalau solusi kamu sebenarnya benar tapi terlalu lambat untuk input yang besar. Ini sinyal untuk memikirkan ulang kompleksitas waktu, bukan logikanya.

Contoh Penggunaan
your solution got TLE on large inputs
solusinya benar tapi kelamaan jalannya kalau input-nya besar — algoritmanya perlu dioptimasi
Duplicate / Distinct / Unique kata sifat Kembar / Berbeda semua

Duplicate berarti ada nilai yang sama muncul lebih dari sekali. Distinct atau unique adalah kebalikannya — semua nilai berbeda, tidak ada yang kembar.

Contoh Penggunaan
return only the distinct values
kembalikan hanya nilai-nilai yang unik, buang yang kembar atau duplikat
Sorted (Ascending/Descending) kata sifat Terurut (Menaik/Menurun)

Kalau soal bilang input sudah sorted, itu petunjuk besar untuk memakai teknik tertentu, misalnya binary search atau two pointers, yang hanya bisa jalan kalau datanya sudah terurut.

Contoh Penggunaan
given a sorted array in ascending order
array-nya sudah terurut dari kecil ke besar — ini isyarat untuk memakai binary search
Contiguous vs Subsequence konsep Berurutan tanpa jeda vs Boleh loncat

Contiguous (substring/subarray) berarti bagian yang harus menempel berurutan, tidak boleh ada yang dilompati. Subsequence berarti urutannya tetap sama tapi boleh ada elemen yang dilewati.

Contoh Penggunaan
[1,3,5] is a subsequence of [1,2,3,4,5] but not a substring
[1,3,5] itu subsequence karena urutannya sama walau loncat-loncat, tapi bukan substring karena tidak menempel berurutan
Out of bounds istilah Melewati batas indeks

Error klasik saat mengakses indeks array yang tidak ada, misalnya arr[10] padahal array-nya cuma punya 5 elemen. Selalu cek batas indeks sebelum atau sesudah loop, terutama saat menggeser i+1 atau i-1.

Contoh Penggunaan
accessing arr[i+1] when i is the last index
mengakses arr[i+1] saat i sudah di elemen terakhir — ini bisa memicu error out of bounds

Struktur Data

Istilah komponen penyimpan data yang paling sering digunakan dalam interview.

Array struktur data Larik / Array

Kumpulan data sejenis yang disimpan berurutan di memori, diakses lewat indeks yang selalu mulai dari 0. Struktur paling dasar dan paling sering dipakai di soal interview.

Contoh Penggunaan
const arr = [10, 20, 30]; arr[0]
arr[0] mengambil elemen pertama, yaitu 10 — indeks array selalu mulai dari 0, bukan 1
Linked list struktur data List berantai

Kumpulan node yang masing-masing menyimpan data dan pointer ke node berikutnya. Berbeda dari array, elemennya tidak menempel di memori sehingga tidak bisa langsung diakses lewat indeks — harus ditelusuri satu per satu dari awal.

Contoh Penggunaan
node.next.next.value
untuk sampai ke elemen ketiga harus lewat .next dua kali — tidak ada cara lompat langsung seperti array[2]
Stack struktur data Tumpukan

Data masuk dan keluar dari ujung yang sama, disebut LIFO (Last In, First Out). Bayangkan tumpukan piring — yang terakhir ditaruh adalah yang pertama diambil.

Contoh Penggunaan
stack.push(1); stack.push(2); stack.pop()
pop() mengambil 2 duluan karena itu yang terakhir masuk, bukan 1
Queue struktur data Antrean

Kebalikan dari stack — data masuk dari satu ujung dan keluar dari ujung lain, disebut FIFO (First In, First Out), seperti antre di kasir. Sering dipakai untuk BFS.

Contoh Penggunaan
queue.enqueue(1); queue.enqueue(2); queue.dequeue()
dequeue() mengambil 1 duluan karena itu yang pertama masuk, sesuai urutan antre
Hash map / Dictionary struktur data Peta hash / Kamus

Menyimpan data sebagai pasangan key-value, dan pencarian berdasarkan key itu sangat cepat, rata-rata O(1). Struktur ini yang paling sering mengubah solusi brute force menjadi optimal.

Contoh Penggunaan
const map = {}; map[nums[i]] = i;
menyimpan tiap angka sebagai key dan indeksnya sebagai value, supaya nanti bisa dicari lagi dengan cepat tanpa loop ulang
Tree / Binary tree struktur data Pohon / Pohon biner

Struktur data berbentuk hierarki dari node-node, dengan satu node "akar" di atas yang bercabang ke bawah. Binary tree berarti tiap node maksimal punya dua anak, yaitu kiri dan kanan.

Contoh Penggunaan
node.left, node.right
setiap node di binary tree punya paling banyak dua anak, diakses lewat .left dan .right
Graph struktur data Graf

Kumpulan node (disebut vertex) yang saling terhubung lewat garis (disebut edge). Berbeda dari tree, graph boleh punya siklus dan satu node bisa terhubung ke banyak node lain tanpa aturan hierarki.

Contoh Penggunaan
graph = {A: ['B','C'], B: ['A','D']}
node A terhubung ke B dan C, sedangkan node B terhubung balik ke A dan juga ke D
Node istilah Simpul

Satu unit data dalam struktur seperti linked list, tree, atau graph. Biasanya berisi sebuah value ditambah referensi ke node lain, misalnya next, left/right, atau neighbors.

Contoh Penggunaan
{ value: 5, next: null }
ini satu node dengan nilai 5, dan next: null artinya dia node terakhir di list
Root / Leaf istilah Akar / Daun

Root adalah node paling atas di sebuah tree, titik awal semua penjelajahan biasanya dimulai. Leaf adalah node paling bawah yang tidak punya anak sama sekali.

Contoh Penggunaan
if (!node.left && !node.right) // leaf
kalau node tidak punya anak kiri maupun kanan, berarti dia leaf, ujung dari pohon itu
Parent / Child istilah Induk / Anak

Hubungan antar-node yang bertetangga langsung di dalam tree. Node yang di atas disebut parent, node di bawahnya disebut child.

Contoh Penggunaan
childNode.parent
lewat childNode.parent kamu bisa naik kembali ke node induknya
Pointer / Reference konsep Penunjuk / Referensi

Variabel yang menyimpan alamat menuju data lain, bukan menyimpan datanya secara langsung. Ini konsep di balik bagaimana linked list dan tree saling terhubung satu sama lain.

Contoh Penggunaan
let a = node; let b = a;
b bukan salinan baru — b dan a menunjuk ke object node yang persis sama di memori
Set struktur data Himpunan

Mirip array tapi tidak boleh ada nilai kembar karena duplikat otomatis dibuang, dan mengecek "apakah nilai ini ada" berjalan cepat. Sering dipakai untuk soal yang meminta cek duplicate atau unique.

Contoh Penggunaan
new Set([1,2,2,3]) menghasilkan {1,2,3}
angka 2 yang kembar otomatis dibuang, sisa satu saja di dalam Set

Algoritma & Kompleksitas

Pola pikir, istilah teknik penyelesaian masalah, dan analisis notasi Big O.

Time complexity konsep Kompleksitas waktu

Ukuran seberapa lambat algoritma kamu ketika inputnya makin besar, ditulis dengan notasi Big O. Ini yang bikin interviewer bertanya "berapa Big O-nya" setelah kamu selesai coding.

Contoh Penggunaan
for i in nums: for j in nums: ...
dua loop bersarang seperti ini biasanya O(n²) — makin besar n, makin lambat secara kuadratik
Space complexity konsep Kompleksitas ruang (memori)

Ukuran seberapa banyak memori tambahan yang dipakai algoritma kamu, di luar memori untuk input aslinya. Membuat array atau hash map baru berarti menambah space complexity.

Contoh Penggunaan
const seen = new Set();
membuat Set baru ini menambah space complexity menjadi O(n), karena bisa menyimpan sampai n elemen
Big O notation konsep Notasi Big O

Cara menulis seberapa efisien algoritma secara matematis, fokus ke pola pertumbuhan saat input membesar, bukan kecepatan pasti dalam detik. Urutan dari cepat ke lambat: O(1), O(log n), O(n), O(n log n), lalu O(n²).

Contoh Penggunaan
O(n) — one loop through the array
satu loop yang melewati tiap elemen sekali itu O(n) — waktunya naik linear sesuai jumlah data
Two pointers teknik Dua penunjuk

Teknik memakai dua variabel indeks yang bergerak di array atau string, biasanya dari kiri dan kanan, untuk menghindari loop bersarang. Sering muncul di soal array yang datanya sudah terurut.

Contoh Penggunaan
let left = 0, right = arr.length - 1;
left mulai dari depan, right dari belakang — keduanya bergerak saling mendekat sampai bertemu di tengah
Sliding window teknik Jendela geser

Teknik untuk soal subarray atau substring — membuat "jendela" rentang indeks yang bergeser sepanjang data, diperbesar atau diperkecil sesuai kondisi, supaya tidak perlu mengecek ulang dari nol setiap kali.

Contoh Penggunaan
window [i...j], geser j lalu geser i kalau kondisi terpenuhi
jendelanya melebar dengan menggerakkan j, lalu menyempit dengan menggerakkan i — tidak perlu looping ulang dari awal tiap kali cek
Binary search teknik Pencarian biner

Cara mencari elemen di data yang sudah terurut dengan cara terus-menerus membagi dua area pencarian. Jauh lebih cepat, yaitu O(log n), dibanding mencari satu per satu yang O(n).

Contoh Penggunaan
mid = Math.floor((left + right) / 2)
tiap langkah, area yang dicek dibagi setengah — makanya jauh lebih cepat daripada mencari satu-satu dari depan
DFS (Depth-first search) algoritma Penelusuran mendalam duluan

Menelusuri graph atau tree dengan cara masuk sedalam mungkin di satu cabang dulu, sebelum kembali dan mencoba cabang lain. Biasanya diimplementasikan dengan rekursi atau stack.

Contoh Penggunaan
dfs(node.left); dfs(node.right);
masuk terus ke cabang kiri sampai mentok, baru kembali dan mencoba cabang lain — itu cara kerja DFS
BFS (Breadth-first search) algoritma Penelusuran melebar duluan

Menelusuri graph atau tree level demi level — semua node di kedalaman yang sama dicek dulu sebelum lanjut ke level berikutnya. Biasanya memakai queue, dan cocok untuk mencari jarak atau langkah terpendek.

Contoh Penggunaan
queue = [root]; while (queue.length) { ... }
memakai queue supaya node yang lebih dekat ke root selalu diproses duluan, level demi level
Dynamic Programming (DP) teknik Pemrograman dinamis

Teknik menyelesaikan masalah besar dengan memecahnya menjadi submasalah lebih kecil, sambil menyimpan hasil submasalah itu supaya tidak dihitung ulang. Biasanya muncul di soal bertema "maximum/minimum ways" atau mirip pola Fibonacci.

Contoh Penggunaan
dp[i] = dp[i-1] + dp[i-2]
hasil dp[i] dibangun dari hasil yang sudah dihitung sebelumnya, tidak dihitung dari nol setiap kali
Greedy algorithm teknik Algoritma rakus/serakah

Strategi mengambil pilihan yang paling menguntungkan saat itu juga di setiap langkah, tanpa mikir jauh ke depan, dengan harapan hasil akhirnya tetap optimal. Tidak selalu benar untuk semua soal, jadi penting menjelaskan kenapa greedy aman dipakai.

Contoh Penggunaan
always pick the largest coin first
tiap langkah selalu ambil koin bernilai terbesar dulu — pilihan paling menguntungkan saat itu, tanpa mikir kombinasi lain
Backtracking teknik Runut-balik

Mencoba satu pilihan, lanjut sampai mentok atau ketahuan salah, lalu mundur (undo) dan mencoba pilihan lain. Sering dipakai untuk soal yang meminta semua kemungkinan kombinasi atau permutasi.

Contoh Penggunaan
path.push(x); backtrack(); path.pop();
path.pop() di akhir itu langkah mundurnya — mengembalikan state sebelum mencoba pilihan lain
Divide and conquer teknik Bagi dan taklukkan

Memecah masalah menjadi beberapa submasalah yang lebih kecil, biasanya dibagi dua, menyelesaikan tiap submasalah secara terpisah biasanya secara rekursif, lalu menggabungkan hasilnya. Merge sort dan binary search adalah contoh klasiknya.

Contoh Penggunaan
mergeSort(kiri) + mergeSort(kanan) lalu digabung
array dibagi dua, masing-masing diurutkan sendiri secara rekursif, baru digabung menjadi satu hasil akhir
Memoization teknik Menyimpan hasil perhitungan

Menyimpan hasil dari perhitungan yang sudah pernah dilakukan, biasanya di object atau map, supaya kalau dibutuhkan lagi tinggal diambil, tidak dihitung ulang. Ini "mesin" di balik banyak solusi dynamic programming.

Contoh Penggunaan
if (memo[n]) return memo[n]; memo[n] = result;
sebelum menghitung ulang, dicek dulu di memo — kalau sudah pernah dihitung, tinggal pakai hasil yang lama

Frasa Klarifikasi Saat Interview

Kalimat penyelamat Bahasa Inggris untuk berkomunikasi dengan profesional bersama interviewer.

Can you clarify what the expected output is for this example? frasa
"Bisa dijelaskan lagi output yang diharapkan untuk contoh ini?"

Pakai ini begitu ada contoh di soal yang formatnya belum kamu mengerti. Interviewer justru senang ditanya begini, karena itu tandanya kamu teliti membaca soal, bukan tanda kamu tidak paham.

Are there any constraints on the input size or value range? frasa
"Apakah ada batasan ukuran atau rentang nilai input?"

Kalau constraints tidak disebutkan di soal, wajib tanya ini duluan sebelum memilih pendekatan — jawabannya menentukan solusi kamu boleh yang sederhana atau harus yang lebih efisien.

Can the input be empty, or contain negative numbers or duplicates? frasa
"Apakah input-nya bisa kosong, atau ada angka negatif/duplikat?"

Ini cara sopan untuk menanyakan edge case tanpa terlihat menebak-nebak. Jawabannya langsung menentukan kondisi apa saja yang perlu ditangani di kode kamu.

Should I optimize for time or space? frasa
"Saya perlu optimalkan dari sisi waktu atau memori?"

Tanyakan ini kalau kamu punya dua opsi solusi dengan trade-off berbeda, misalnya lebih cepat tapi memakai lebih banyak memori. Pertanyaan ini menunjukkan kamu paham ada trade-off, bukan cuma mencari satu jawaban.

Let me restate the problem to make sure I understand it correctly. frasa
"Saya coba ulangi soalnya biar yakin paham dengan benar."

Kalimat penyelamat kalau kepala tiba-tiba blank. Mengucapkan ini memberi kamu waktu untuk berpikir tanpa hening yang canggung, sekaligus mengecek pemahaman kamu benar atau tidak.
