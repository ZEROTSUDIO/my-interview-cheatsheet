Box Model & Selectors

Fondasi tata letak CSS — cara browser menghitung ukuran elemen dan cara memilih elemen secara presisi.

📦
CSS Box Model
Fondasi semua tata letak CSS
Sering Ditanya
Setiap elemen HTML adalah "kotak" dengan 4 lapisan: content (konten asli) → padding (ruang dalam, ikut background) → border (garis tepi) → margin (ruang luar, transparan).

Kunci interview: box-sizing: content-box (default — width tidak termasuk padding/border) vs box-sizing: border-box (width SUDAH termasuk padding dan border — dipakai hampir semua proyek modern).
content-box vs border-box
CSS
/* Default — width BELUM termasuk padding/border */
.box { box-sizing: content-box; width: 200px; padding: 20px; border: 4px solid; }
/* Total: 200 + 40 + 8 = 248px */

/* Modern — width SUDAH termasuk segalanya */
.box { box-sizing: border-box; width: 200px; padding: 20px; border: 4px solid; }
/* Total tetap: 200px */
Reset global terbaik
CSS
/* Tempel di paling atas style.css */
*, *::before, *::after {
  box-sizing: border-box;
}

Flexbox & Grid

Flexbox untuk satu dimensi, Grid untuk dua dimensi.

↔️
Flexbox — Tata Letak Satu Dimensi
Container & item properties, centering tricks
Sering Ditanya
Flexbox bekerja pada dua sumbu: main axis (arah flex-direction) dan cross axis (tegak lurusnya). justify-content = distribusi di main axis. align-items = posisi di cross axis (satu baris). flex: 1 = shorthand grow+shrink+basis, membuat item mengisi ruang kosong.
CSS — Flexbox Essentials
.container {
  display: flex;
  flex-direction: row;          /* row | column */
  justify-content: space-between; /* distribusi main axis */
  align-items: center;          /* posisi cross axis */
  flex-wrap: wrap;              /* turun baris kalau sempit */
  gap: 16px;
}
.item { flex: 1; }              /* ambil ruang tersisa */
.card { display:flex; flex-direction:column; }
.card .btn { margin-top: auto; } /* dorong tombol ke bawah */

CSS Grid — Tata Letak Dua Dimensi
fr, minmax, auto-fit, template areas
Sering Ditanya
fr = fractional unit, proporsi dari ruang sisa. repeat(auto-fit, minmax(200px, 1fr)) = grid responsif otomatis tanpa media query — kolom akan menyesuaikan jumlahnya sendiri. grid-area memungkinkan layout semantik seperti header-sidebar-main-footer.
Grid Responsif Otomatis
CSS
.grid {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(200px, 1fr));
  gap: 16px;
}
.hero { grid-column: 1 / -1; /* span semua kolom */ }
Template Areas (Layout Semantik)
CSS
.layout {
  display: grid;
  grid-template-areas:
    "header  header"
    "sidebar main  "
    "footer  footer";
  grid-template-columns: 200px 1fr;
}
header  { grid-area: header; }
.sidebar{ grid-area: sidebar; }
main    { grid-area: main; }

Positioning & Z-index

Mengontrol posisi elemen di luar aliran normal dokumen HTML.

📌
static / relative / absolute / fixed / sticky
Kapan dan bagaimana pakai masing-masing nilai position
Sering Ditanya
static — default, tidak bisa pakai top/left. relative — digeser dari posisinya sendiri, ruang aslinya tetap ada. absolute — lepas dari aliran dokumen, posisi relatif ke ancestor non-static terdekat. fixed — relatif ke viewport, tidak ikut scroll. sticky — gabungan relative + fixed: ikut scroll sampai offset tertentu lalu menempel.
Pola: parent relative + child absolute
CSS
.card { position: relative; }
.badge {
  position: absolute;
  top: 8px; right: 8px;
}
nav { position: sticky; top: 0; z-index: 100; }
.overlay {
  position: fixed;
  inset: 0; /* top:0;right:0;bottom:0;left:0 */
  background: rgba(0,0,0,0.5);
}
Z-index & Stacking Context
CSS
.modal    { z-index: 1000; }
.dropdown { z-index: 500;  }
.header   { z-index: 100;  }

/* Buat stacking context tanpa efek samping */
.isolated { isolation: isolate; }

Responsive Design & Media Queries

Tampilan adaptif di semua ukuran layar dengan pendekatan mobile-first modern.

📱
Media Queries & Unit Responsif Modern
clamp(), min(), dvh, mobile-first strategy
Sering Ditanya
Mobile-first: tulis default untuk layar kecil, override dengan min-width untuk layar besar. Lebih efisien karena device kecil unduh lebih sedikit CSS. clamp(min, preferred, max) = ukuran fluid yang terbatas. dvh (dynamic viewport height) = lebih aman dari vh di mobile karena memperhitungkan address bar.
Mobile-first Media Queries
CSS
/* Default: mobile */
.grid { grid-template-columns: 1fr; }

/* ≥ 768px: tablet */
@media (min-width: 768px) {
  .grid { grid-template-columns: repeat(2, 1fr); }
}
/* ≥ 1024px: desktop */
@media (min-width: 1024px) {
  .grid { grid-template-columns: repeat(3, 1fr); }
}
@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; }
}
Unit Responsif Modern
CSS
/* clamp: fluid antara 1rem – 2rem */
h1 { font-size: clamp(1rem, 4vw + 1rem, 2rem); }

/* Container yang aman */
.wrap {
  width: min(100% - 48px, 1140px);
  margin-inline: auto;
}
/* Tinggi hero aman di mobile */
.hero { min-height: 100dvh; }

Animations & Transitions

Membuat antarmuka yang terasa hidup — smooth di GPU, tidak menyebabkan reflow.

✨
Transition vs Animation & GPU Compositing
transform & opacity = aman. Width/height = menyebabkan reflow
Sering Ditanya
Transition = animasi antara dua state, butuh pemicu. Animation + keyframes = mandiri, bisa loop.

Performa kritis: transform dan opacity hanya melibatkan compositor layer (GPU) — tidak ada reflow. Property seperti width, height, top, margin menyebabkan layout recalculation seluruh halaman = lambat. Selalu prefer transform: scale() daripada mengubah width.
Transition — state change
CSS
.btn {
  transition: background 0.2s ease,
              transform  0.2s ease;
}
.btn:hover {
  background: #79c0ff;
  transform: translateY(-2px); /* ✅ GPU */
}
/* Jangan: margin-top: -2px; ❌ reflow */
Animation + Keyframes
CSS
@keyframes fadeUp {
  from { opacity: 0; transform: translateY(20px); }
  to   { opacity: 1; transform: translateY(0); }
}
.card { animation: fadeUp 0.4s ease forwards; }

@keyframes spin { to { transform: rotate(360deg); } }
.loader { animation: spin 1s linear infinite; }

DOM & Events

Manipulasi elemen HTML dan penanganan event yang efisien dengan event delegation.

🌐
DOM Manipulation & Event Delegation
Seleksi, modifikasi elemen, bubbling & delegation pattern
Sering Ditanya
Event Bubbling: event naik dari anak ke parent ke grandparent sampai window. Event Delegation: manfaatkan bubbling — pasang SATU listener di parent, tangkap event dari semua anak. Keuntungan: hemat memori, otomatis bekerja untuk elemen yang ditambahkan dinamis. event.target = elemen yang diklik. event.currentTarget = elemen yang dipasangi listener.
DOM Essentials
JavaScript
// Seleksi
const el = document.querySelector('.card');
const all = document.querySelectorAll('.item');

// Konten
el.textContent = 'Halo!'; // ✅ safe
el.innerHTML = 'Halo'; // ⚠️ XSS risk

// Class
el.classList.add('active');
el.classList.toggle('open');

// Dataset
el.dataset.userId; // akses data-user-id
Event Delegation Pattern
JavaScript
// ✅ Satu listener di parent
document.querySelector('.list')
  .addEventListener('click', (e) => {
    const btn = e.target.closest('.btn');
    if (!btn) return; // klik bukan di .btn

    // e.stopPropagation() — hentikan bubbling
    // e.preventDefault()  — cegah default (link)
    console.log('ID:', btn.dataset.id);
  });

Event Loop & Async JavaScript

Urutan eksekusi Promise vs setTimeout, debounce, dan throttle — topik favorit interviewer.

🔄
Event Loop, Debounce & Throttle
Microtask vs macrotask, pembatasan frekuensi panggilan fungsi
Sulit
JavaScript single-threaded. Event Loop menjalankan: (1) semua kode sync, (2) kosongkan microtask queue (Promise .then, queueMicrotask), (3) ambil satu task dari macrotask queue (setTimeout, setInterval, DOM events), lalu ulangi dari 2. Artinya: Promise selalu jalan sebelum setTimeout, seberapa pun cepatnya timeout.
Urutan Eksekusi (tebak outputnya!)
JavaScript
console.log('1 — sync');
setTimeout(() => console.log('2 — macro'), 0);
Promise.resolve().then(() => console.log('3 — micro'));
console.log('4 — sync');
// Output: 1, 4, 3, 2
Debounce vs Throttle
JavaScript
// Debounce: tunggu SELESAI, lalu panggil sekali
function debounce(fn, delay) {
  let t; return (...a) => { clearTimeout(t);
    t = setTimeout(() => fn(...a), delay); };
}
// Throttle: panggil MAKSIMAL sekali per N ms
function throttle(fn, limit) {
  let last = 0; return (...a) => {
    if (Date.now() - last >= limit) {
      last = Date.now(); fn(...a); }};
}

Performance & Accessibility

Lazy loading, layout thrashing, Core Web Vitals, dan ARIA — topik senior frontend interview.

🚀
Web Performance & Accessibility (a11y)
IntersectionObserver, Layout Thrashing, Core Web Vitals, ARIA
Senior Level
Core Web Vitals: LCP (Largest Contentful Paint) <2.5s, CLS (Cumulative Layout Shift) <0.1, INP (Interaction to Next Paint) <200ms. Layout Thrashing = baca dan tulis DOM bergantian dalam loop — browser terpaksa flush layout setiap kali. Solusi: batch semua pembacaan dulu, lalu tulis semua. Accessibility: gunakan elemen semantik (<button>, bukan <div onclick>), pastikan focus visible, tambahkan ARIA hanya jika HTML tidak cukup ekspresif.
Lazy Loading — Intersection Observer
JavaScript
const observer = new IntersectionObserver(
  (entries) => {
    entries.forEach(entry => {
      if (entry.isIntersecting) {
        const img = entry.target;
        img.src = img.dataset.src; // muat gambar
        observer.unobserve(img);   // stop observasi
      }
    });
  },
  { rootMargin: '200px' } // mulai 200px sebelum terlihat
);
document.querySelectorAll('img[data-src]')
  .forEach(img => observer.observe(img));
Accessibility — ARIA & Focus
HTML + CSS
<button aria-label="Tutup" aria-expanded="false"
        aria-controls="menu">☰</button>
<div aria-live="polite">Tersimpan!</div>

/* Jangan hapus outline — custom saja */
:focus-visible {
  outline: 2px solid #58a6ff;
  outline-offset: 3px;
}
/* Jangan: * { outline: none } ❌ */
